# Gauntlet Goal

A Codex skill that turns a concrete task into a ready-to-paste `/goal` objective using the Gauntlet Loop.

## Install

Copy this directory into your Codex skills directory as `gauntlet-goal`, then invoke it explicitly with `$gauntlet-goal`.

## Contents

- `SKILL.md` — skill instructions
- `agents/openai.yaml` — Codex skill metadata

The skill generates the goal text; it does not run the goal by itself.
